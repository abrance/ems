# Requirements Document

# Introduction

日报原图对人可读、对系统不可读。本功能用「OCR + 模板提取」把每篇《广东电力现货市场运行日报》里的表格与正文指标还原成结构化数值并落库，供页面直接以表格阅读，也为后续趋势图与价格联动提供数据源。

触发方式为手动：管理员在「信息管理」中对某份日报点「解析数据」。

# Glossary

- **系统**: OpenLEMS 能源管理系统。
- **OCR 服务**: `apps/model-ocr`（PP-OCR + MNN，cops 部署单元），lems 通过 `OCR_BASE_URL` 经共享 docker 网络访问。
- **模板**: 日报版式的归一化坐标描述（相对图片宽高的位置），与图片分辨率无关。
- **运行日**: 指标所属的交易日。日报里的「表2」承载的是滞后运行日（实测 T-2）的日前/实时成交电价。
- **日报日**: 承载指标的日报本身所属日期；同一运行日的同一指标可能来自不同日报日。

# Requirements

## 需求 1：从日报图片提取结构化指标

**用户故事**：作为运维人员，我希望日报里的表格与关键指标能变成数值，这样我不用逐张放大看图抄数。

**验收标准**

1. 当日报已采集且 OCR 服务可用时，系统应能提取以下数据：
   - 正文摘要：日前加权平均电价、燃煤均价、燃气均价、日前成交最高价、日前成交最低价
   - 表1(一) 日前申报信息：发电侧的最高/最低/平均电价、自主/默认申报台数；零价及以下与报价600以上两个区间的申报容量、煤机容量、气机容量、新能源容量（含占市场比例与环比）
   - 表1(二) 日前成交电价：发电侧/燃煤/燃气/新能源 的最高电价（含出现时刻）、最低电价（含出现时刻）、平均电价、电价环比
   - 表2(一) 日前成交电价、表2(二) 实时成交电价：发电侧/燃煤/燃气 的同结构指标，运行日为日报日 T-2
2. 每条指标应记录运行日、数据集、对象、指标名、数值、单位、环比、占比、出现时刻、来源表、OCR 置信度。
3. 指标应按数据集与对象分组展示，环比以角标呈现（涨红跌绿）。
4. 每日报文摘、日前成交电价与正文摘要应交叉一致；表2(一) 与其滞后运行日已采集的日报表1(二) 应一致。
5. 当 09-18 这类 1587×2245 的低分辨率日报与 2381×3367 的日报混存时，提取结果应一致（模板使用归一化坐标）。

## 需求 2：可追溯与可重跑

**用户故事**：作为运维人员，我希望每次解析留痕、可重复执行，这样数值可疑时能定位是 OCR 问题还是解析问题。

**验收标准**

1. 每次解析应记录：状态（ok / 部分告警 / 失败）、OCR 档位、页数、OCR 耗时、告警列表、提取器版本、原始产物、更新时间。
2. 同一日报重复解析应覆盖旧结果，不产生重复指标（按 运行日+数据集+对象+指标 唯一）。
3. 解析失败（如 OCR 服务不可用）不应影响已采集的日报图片档案。
4. 校验不通过时应产出可读告警而不是静默写入错误数据。

## 需求 3：明确的边界

**验收标准**

1. 图片类数据（图1 报价分布、图2-1/2-2 地市节点电价地图、图4 加权价格曲线）本期不提取，页面应说明数据来源范围。
2. 解析为管理员手动触发；未登录/非管理员不可触发。
3. OCR 服务地址通过环境变量配置，缺省时给出可读提示而不是崩溃。
